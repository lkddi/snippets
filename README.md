# Snippets

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

一个 Alfred 风格的 macOS 桌面启动器，基于 Electron + React + TypeScript 构建。

全局热键一键唤起，聚合搜索本机应用、文件与代码片段，并内置剪贴板历史管理。

> **来源说明**：本项目基于 [后盾人](https://www.houdunren.com/)（houdunren.com）的 Electron 开发教程及配套源码学习、修改而来，
> 在原教程示例的基础上做了功能扩展与体验优化，详见文末[来源与致谢](#来源与致谢)。

## 功能特性

- **聚合搜索**：一个输入框同时检索本机应用、指定目录下的文件与代码片段
- **拼音检索**：输入 `wx` 可命中「微信」，全拼与首字母均支持
- **网页搜索兜底**：结果末尾附带搜索引擎条目，回车即用默认浏览器打开
- **全局热键**：自定义唤起组合键；注册失败时设置页会给出占用原因
- **剪贴板历史**：默认双击 `Option` 呼出面板，失焦自动隐藏，支持保留天数
- **代码片段管理**：分类 + 内容编辑 + 代码高亮，数据保存在本地 SQLite
- **托盘常驻 / 开机启动 / 隐藏程序坞图标**：纯菜单栏驻留，不占 Dock 位
- **多桌面友好**：搜索窗、剪贴板面板悬浮于所有 Space 与全屏应用之上

## 安装与首次启动

### macOS

从 [Releases](https://github.com/lkddi/snippets/releases) 下载 `Snippets-<版本>-arm64.dmg`，拖入「应用程序」即可。

首次打开若提示「无法验证开发者」，到「系统设置 → 隐私与安全性」点击「仍要打开」；
或执行：

```bash
xattr -dr com.apple.quarantine /Applications/Snippets.app
```

启动后应用**只驻留菜单栏，不显示主窗口**，这是设计行为。按下默认快捷键 `Option + Space` 即可呼出搜索窗。

### Windows / Linux

```bash
pnpm build:win     # NSIS 安装包
pnpm build:linux   # AppImage / snap / deb
```

> 主要开发与验证环境是 macOS，Windows / Linux 为构建配置支持，未做完整交互验证。

## 使用说明

### 唤起搜索窗

- **默认快捷键**：`Option + Space`（macOS）
- **托盘图标左键**：切换搜索窗显示 / 隐藏
- **托盘右键**：打开菜单（搜索窗、剪贴板、设置、开机启动、退出）

关闭窗口不会退出应用；彻底退出请用托盘菜单的「退出 Snippets」。

修改快捷键：设置页 → 搜索快捷键 → 直接用键盘按下想要的组合（必须包含 `Command` / `Control` / `Option` 之一）。
保存后如果显示红色提示，说明该组合被系统或其他应用占用，需要先在「系统设置 → 键盘 → 键盘快捷键」里释放。

### 聚合搜索

输入即搜（150ms 防抖），结果按 **应用 → 文件 → 片段 → 网页搜索** 分组排列。

| 按键 | 作用 |
| --- | --- |
| `↑` / `↓` | 上下移动选中项（到头会循环） |
| `Enter` | 执行：启动应用 / 打开文件 / 复制片段 / 网页搜索 |
| `Esc` | 收起搜索窗 |
| 点击齿轮图标 | 打开配置窗口 |

匹配规则：

- **应用**：匹配应用名、拼音全拼与首字母，以及 `Info.plist` 里的本地化中文名
- **文件**：只在设置里配置的「搜索目录」内递归检索（默认深度 4 层、最多返回 6 条）
- **片段**：标题与内容都参与匹配，标题额外支持拼音，输入 `wx` 即可命中「微信使用技巧」
- **网页搜索**：始终作为最后一项出现，回车用设置中的搜索引擎打开

### 剪贴板历史

- **呼出方式**：默认**连按两次 `Option`**（不占用全局快捷键）；也可在设置里改为自定义组合键
- **面板操作**：`↑` / `↓` 选择，`Enter` 粘贴到当前前台应用，面板上的删除按钮可单条删除、清空可一键全清
- **自动记录**：监听系统剪贴板，文本内容写入本地数据库
- **自动清理**：按「保留天数」删除旧记录，默认 7 天，设 `0` 表示永久保留
- **自动隐藏**：面板失焦即收起，参考 Maccy 的交互

### 代码片段管理

从搜索窗齿轮图标或托盘菜单进入配置窗口：

- 新增 / 编辑 / 删除片段，支持分类归类
- 片段标题用于搜索匹配，内容执行时复制到剪贴板
- 删除分类时，分类下的片段会移动到「未分类」，不会连带删除

### 设置项

| 设置项 | 说明 |
| --- | --- |
| 搜索快捷键 | 全局唤起搜索窗的组合键，按下即录制并保存 |
| 剪贴板快捷键 | 默认「双击 Option」，也可录制自定义组合键 |
| 剪贴板保留天数 | `0` 为永久保留，范围 0–3650 天 |
| 数据库目录 | 存放 `hd.db` 的目录，切换后自动重建连接 |
| 搜索引擎 | 百度 / Google / Bing / DuckDuckGo，用作网页搜索兜底 |
| 搜索目录 | 参与文件检索的目录，可添加多个 |
| 开机启动 | 通过系统登录项实现 |
| 隐藏程序坞图标 | 仅 macOS，开启后应用以 accessory 模式常驻菜单栏 |

## 数据存放位置

| 内容 | 路径 |
| --- | --- |
| 片段 / 分类 / 剪贴板记录 | `<数据库目录>/hd.db`（默认在桌面，可在设置中更改） |
| 主进程配置（数据库目录等） | `~/Library/Application Support/snippets/snippets-config.json` |

`hd.db` 是标准 SQLite 文件（WAL 模式），备份时连同 `hd.db-wal`、`hd.db-shm` 一起复制即可。

## 常见问题

**按快捷键没有反应？**
先去设置页确认快捷键状态是否正常。若提示被占用，检查系统快捷键冲突；`Command + Space` 被 Spotlight 占用、`Control + Space` 被输入法切换占用，需先在系统设置中关闭对应功能。

**搜不到某个应用？**
应用列表来自系统应用目录扫描，非标准路径安装的 App 可能不在范围内。

**搜不到文件？**
文件搜索只覆盖设置里的「搜索目录」，请先把目标文件夹加进去；深层嵌套目录受 4 层深度限制。

**隐藏了程序坞图标，怎么退出应用？**
点菜单栏图标 → 「退出 Snippets」。

**中文输入法下打不出拼音首字母？**
请切到英文输入状态再输入，拼音匹配基于输入的字母串。

## 从源码运行

环境要求：Node.js 18+、pnpm。

```bash
pnpm install       # 安装依赖
pnpm dev           # 开发模式
pnpm typecheck     # 类型检查
pnpm build:mac     # 构建 macOS dmg
```

> `better-sqlite3`、`uiohook-napi` 是原生模块，首次安装会针对 Electron ABI 重新编译；
> 若构建报 `NODE_MODULE_VERSION` 不匹配，执行 `pnpm rebuild` 或重新 `pnpm install`。

## 项目结构

```
src/
├── main/                # 主进程
│   ├── apps.ts          # 应用扫描、中文名与拼音匹配
│   ├── files.ts         # 文件目录扫描
│   ├── webSearch.ts     # 网页搜索引擎跳转
│   ├── shortCut.ts      # 全局快捷键注册与状态回显
│   ├── clipboard.ts     # 剪贴板监听、双击 Option、历史读写
│   ├── tray.ts          # 托盘图标与菜单
│   ├── loginItem.ts     # 开机启动
│   ├── dockIcon.ts      # 程序坞图标显隐
│   ├── windows.ts       # 窗口注册表（懒创建 + 复用）
│   ├── createWindow.ts  # 窗口创建封装
│   └── db/              # SQLite 连接、建表、查询、IPC 数据层
├── preload/             # contextBridge 暴露的安全 API
└── renderer/            # React 渲染层
    ├── pages/           # 搜索窗、配置、片段、分类、剪贴板、欢迎页
    ├── components/      # 结果列表、搜索框、快捷导航等
    └── hooks/           # 搜索、选中、剪贴板等逻辑
```
