# 灵犀

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)
[![Release](https://img.shields.io/github/v/release/lkddi/snippets)](https://github.com/lkddi/snippets/releases/latest)
[![Platform](https://img.shields.io/badge/platform-macOS%20arm64-lightgrey)](https://github.com/lkddi/snippets/releases/latest)

一个 Alfred 风格的 macOS 桌面启动器，基于 Electron + React + TypeScript 构建。

全局热键一键唤起，聚合搜索本机应用、文件与代码片段，内置剪贴板历史管理、按应用绑定的启动热键与自定义网页搜索引擎。

> **来源说明**：本项目基于 [后盾人](https://www.houdunren.com/)（houdunren.com）的 Electron 开发教程及配套源码学习、修改而来，
> 在原教程示例的基础上做了功能扩展与体验优化，详见文末[来源与致谢](#来源与致谢)。

## 功能特性

- **聚合搜索**：一个输入框同时检索本机应用、指定目录下的文件与代码片段
- **拼音检索**：输入 `wx` 可命中「微信」，全拼与首字母均支持
- **网页搜索兜底**：结果末尾附带搜索引擎条目，回车即用默认浏览器打开
- **多搜索引擎**：内置百度、Google、必应、DuckDuckGo、GitHub、京东、淘宝等，
  输入「关键字 + 空格 + 关键词」即可定向搜索，也可自定义增删改、单独启停
- **全局热键**：自定义唤起组合键；注册失败时设置页会给出占用原因
- **应用快捷键**：给单个应用绑定热键，按一下启动、再按一下隐藏；
  注册前会检查系统 / 其他应用是否已占用，冲突时直接说明被谁占了
- **剪贴板历史**：默认双击 `Option` 呼出面板，失焦自动隐藏，支持保留天数
- **代码片段管理**：分类 + 内容编辑 + 代码高亮，数据保存在本地 SQLite
- **左右分栏设置窗**：左侧分区导航（通用 / 快捷键 / 应用快捷键 / 搜索 / 剪贴板 / 数据），
  代码片段也收在其中，`⌘,` 随时打开
- **托盘常驻 / 开机启动 / 隐藏程序坞图标**：纯菜单栏驻留，不占 Dock 位
- **多桌面友好**：搜索窗、剪贴板面板悬浮于所有 Space 与全屏应用之上

## 安装与首次启动

### macOS

从 [Releases](https://github.com/lkddi/snippets/releases) 下载 `灵犀-<版本>-arm64.dmg`，拖入「应用程序」即可。

首次打开若提示「无法验证开发者」，到「系统设置 → 隐私与安全性」点击「仍要打开」；
或执行：

```bash
xattr -dr com.apple.quarantine /Applications/灵犀.app
```

启动后应用**只驻留菜单栏，不显示主窗口**，这是设计行为。按下默认快捷键 `Option + Space` 即可呼出搜索窗。

### Windows / Linux

```bash
pnpm build:win     # NSIS 安装包
pnpm build:linux   # AppImage / snap / deb
```

> 主要开发与验证环境是 macOS，Windows / Linux 为构建配置支持，未做完整交互验证。

## 使用说明

### 唤起搜索窗

- **默认快捷键**：`Option + Space`（macOS）
- **托盘图标左键**：切换搜索窗显示 / 隐藏
- **托盘右键**：打开菜单（搜索窗、剪贴板、代码片段、设置、开机启动、退出）
- **`⌘,`**：直接打开设置窗（也可从搜索窗右侧齿轮进入）

关闭窗口不会退出应用；彻底退出请用托盘菜单的「退出 灵犀」。

修改快捷键：设置页 → 快捷键 → 直接用键盘按下想要的组合（必须包含 `Command` / `Control` / `Option` 之一）。
保存后如果显示红色提示，说明该组合被系统或其他应用占用，需要先在「系统设置 → 键盘 → 键盘快捷键」里释放。

### 聚合搜索

输入即搜（150ms 防抖），结果按 **应用 → 文件 → 片段 → 网页搜索** 分组排列。

| 按键 | 作用 |
| --- | --- |
| `↑` / `↓` | 上下移动选中项（到头会循环） |
| `Enter` | 执行：启动应用 / 打开文件 / 复制片段 / 网页搜索 |
| `Esc` | 收起搜索窗 |
| 点击齿轮图标 | 打开设置窗并定位到「代码片段」 |

匹配规则：

- **应用**：匹配应用名、拼音全拼与首字母，以及 `Info.plist` 里的本地化中文名
- **文件**：只在设置里配置的「搜索目录」内递归检索（默认深度 4 层、最多返回 6 条）
- **片段**：标题与内容都参与匹配，标题额外支持拼音，输入 `wx` 即可命中「微信使用技巧」
- **网页搜索**：始终作为最后一项出现，标题会写明将用哪个引擎搜索

#### 用关键字指定搜索引擎

网页搜索行支持「关键字 + 空格 + 关键词」直接切引擎，不必先进设置：

| 输入 | 实际动作 |
| --- | --- |
| `github electron` | 用 GitHub 仓库搜索 `electron` |
| `jd 机械键盘` | 用京东搜索「机械键盘」 |
| `bd 天气预报` | 用百度搜索「天气预报」 |
| `快捷键`（无关键字） | 用设置里的默认引擎搜索 |

关键字必须后接空格，只匹配已启用的引擎；`githubabc` 不会被当成 `github` 搜索。
引擎的增删改见[设置项 → 搜索](#设置项)。

### 剪贴板历史

- **呼出方式**：默认**连按两次 `Option`**（不占用全局快捷键）；也可在设置里改为自定义组合键
- **面板操作**：`↑` / `↓` 选择，`Enter` 粘贴到当前前台应用，面板上的删除按钮可单条删除、清空可一键全清
- **自动记录**：监听系统剪贴板，文本内容写入本地数据库
- **自动清理**：按「保留天数」删除旧记录，默认 7 天，设 `0` 表示永久保留
- **自动隐藏**：面板失焦即收起，参考 Maccy 的交互

### 应用快捷键

给单个应用绑定一个全局热键，行为是「一键唤起 / 再按收起」：

- **入口**：设置 → 应用快捷键 → 添加应用（弹窗内按名称搜索，中英文都支持）
- **录制方式**：点击右侧方框后直接按下组合键；必须包含 `Command` / `Control` / `Option`，
  避免录出会抢走正常输入的裸字母
- **按下行为**：应用没在前台就启动或切到前台；已在前台时再按一次把它隐藏
- **冲突检测**：保存前依次检查搜索快捷键、剪贴板快捷键、其它应用的绑定，
  再向系统试注册一次，冲突时明确提示「已被「微信」占用」或「已被其他应用占用」
- **生效状态**：列表里直接显示「已生效 · Option+Space」；失败会在该行标红，下次启动自动重放注册
- **数据位置**：绑定关系存在配置表 `appShortCuts` 字段，随 `hd.db` 一起走

> **首次使用隐藏功能时**，系统会弹一次「灵犀 想要控制 System Events」的授权。
> 这是 macOS 的「自动化」权限，只用于把前台应用收起；拒绝授权也不影响启动，
> 只是再按一次会退化成「重新激活该应用」。可在「系统设置 → 隐私与安全性 → 自动化」里补授权。

### 代码片段管理

从托盘菜单「代码片段」、搜索窗齿轮或设置窗左侧「代码片段」进入：

- 新增 / 编辑 / 删除片段，支持分类归类
- 片段标题用于搜索匹配，内容执行时复制到剪贴板
- 删除分类时，分类下的片段会移动到「未分类」，不会连带删除

### 设置项

设置窗是左右分栏：左侧导航分「偏好设置」（通用 / 快捷键 / 应用快捷键 / 搜索 / 剪贴板 / 数据）
与「内容」（代码片段），右侧只渲染当前分区。改动即时保存，没有单独的「保存」按钮。

**通用**

| 设置项 | 说明 |
| --- | --- |
| 登录时启动 | 通过系统登录项实现，开机后只驻留菜单栏、不弹窗 |
| 隐藏程序坞图标 | 仅 macOS，开启后以 accessory 模式常驻菜单栏 |
| 菜单栏图标 | 常驻，点按唤起搜索、右键打开菜单 |

**快捷键**

| 设置项 | 说明 |
| --- | --- |
| 打开搜索 | 全局唤起搜索窗；可清除，清除后仍能从托盘唤起 |
| 唤起剪贴板 | 默认「连按两次 Option」，也可录制自定义组合键，可一键恢复默认 |

**应用快捷键**：见[应用快捷键](#应用快捷键)，添加 / 重录 / 移除后立即生效。

**搜索**

| 设置项 | 说明 |
| --- | --- |
| 默认搜索引擎 | 不带关键字时用它；以按钮形式列出全部已启用引擎 |
| 搜索引擎与关键字 | 内置 9 个（百度、Google、必应、DuckDuckGo、GitHub、京东、淘宝、知乎、哔哩哔哩），可启停、可改关键字；其中知乎与哔哩哔哩默认停用 |
| 搜索目录 | 参与文件检索的目录，可添加多个，改动后自动清空文件索引缓存 |

自定义引擎的三条约束：

| 字段 | 规则 |
| --- | --- |
| 触发关键字 | 1–16 位小写字母 / 数字 / 短横线，全局唯一 |
| 搜索地址 | 必须包含 `{query}`（也接受 `{q}`）表示关键词位置，搜索时自动 URL 编码、空格转 `+` |
| 启用 | 关闭后既不参与关键字匹配，也不会被选为默认引擎 |

内置引擎不能删除（只能停用），保证默认搜索永远有可用项；默认引擎被停用时自动退回第一个启用的引擎。

**剪贴板**

| 设置项 | 说明 |
| --- | --- |
| 保存时长 | `0` 为永久保留，范围 0–3650 天，超出即自动清理 |

**数据**

| 设置项 | 说明 |
| --- | --- |
| 存储目录 | 存放 `hd.db` 的目录，切换后自动重建连接 |

### 托盘菜单

## 数据存放位置

| 内容 | 路径 |
| --- | --- |
| 片段 / 分类 / 剪贴板记录 | `<数据库目录>/hd.db`（默认在桌面，可在设置中更改） |
| 其它设置（快捷键、搜索引擎、应用快捷键绑定等） | `hd.db` 的 `config` 表，JSON 存在 `content` 字段 |
| 主进程配置（数据库目录、是否已初始化） | `~/Library/Application Support/snippets/snippets-config.json` |

`hd.db` 是标准 SQLite 文件（WAL 模式），备份时连同 `hd.db-wal`、`hd.db-shm` 一起复制即可。
数据库目录必须单独存在 `snippets-config.json` 里——它得在打开数据库之前就知道，没法存在数据库自身中。

## 常见问题

**按快捷键没有反应？**
先去设置页确认快捷键状态是否正常。若提示被占用，检查系统快捷键冲突；`Command + Space` 被 Spotlight 占用、`Control + Space` 被输入法切换占用，需先在系统设置中关闭对应功能。

**应用快捷键只能启动、再按一次收不起来？**
隐藏前台应用要走 macOS「自动化」权限。首次触发时系统会询问是否允许控制 System Events，选「允许」；
若当时点了拒绝，到「系统设置 → 隐私与安全性 → 自动化」里勾选 灵犀 对应的 System Events 即可。

**输入 `github 关键词` 没切到 GitHub？**
检查三点：该引擎是否处于启用状态、关键字后是否真的有空格、关键字是否被别的引擎占用（设置页会提示重复）。

**设置窗里内容显示不全？**
设置窗最小尺寸是 940×600，窗口被拖得太小时右侧内容会重新排版，拉大即可。

**搜不到某个应用？**
应用列表来自系统应用目录扫描，非标准路径安装的 App 可能不在范围内。

**搜不到文件？**
文件搜索只覆盖设置里的「搜索目录」，请先把目标文件夹加进去；深层嵌套目录受 4 层深度限制。

**隐藏了程序坞图标，怎么退出应用？**
点菜单栏图标 → 「退出 灵犀」。

**中文输入法下打不出拼音首字母？**
请切到英文输入状态再输入，拼音匹配基于输入的字母串。

## 从源码运行

环境要求：Node.js 18+、pnpm。

```bash
pnpm install       # 安装依赖
pnpm dev           # 开发模式
pnpm typecheck     # 类型检查
pnpm build:mac     # 构建 macOS dmg
```

> `better-sqlite3`、`uiohook-napi` 是原生模块，首次安装会针对 Electron ABI 重新编译；
> 若构建报 `NODE_MODULE_VERSION` 不匹配，执行 `pnpm rebuild` 或重新 `pnpm install`。

## 项目结构

```
src/
├── main/                     # 主进程
│   ├── apps.ts               # 应用扫描、中文名 / 拼音匹配、bundleId 与图标
│   ├── files.ts              # 文件目录扫描
│   ├── webEngines.ts         # 内置搜索引擎清单、URL 模板与配置清洗
│   ├── webSearch.ts          # 关键字解析（github xx）与引擎跳转
│   ├── shortCut.ts           # 搜索窗全局快捷键注册与状态回显
│   ├── appShortcuts.ts       # 按应用绑定的热键：占用检测、启动 / 隐藏、持久化
│   ├── clipboard.ts          # 剪贴板监听、双击 Option、历史读写
│   ├── menu.ts               # 应用菜单（含 ⌘, 打开设置，保留 Edit 角色）
│   ├── tray.ts               # 托盘图标与菜单
│   ├── loginItem.ts          # 开机启动
│   ├── dockIcon.ts           # 程序坞图标显隐
│   ├── windows.ts            # 窗口注册表（懒创建 + 复用 + 指定 hash 跳转）
│   ├── createWindow.ts       # 窗口创建封装
│   └── db/                   # SQLite 连接、建表、查询、IPC 数据层
├── preload/                  # contextBridge 暴露的安全 API
└── renderer/                 # React 渲染层
    ├── layouts/Config/       # 左右分栏设置窗骨架（左侧导航 + 右侧 Outlet）
    ├── pages/                # 设置各分区、片段、分类、剪贴板、搜索窗、欢迎页
    │   └── Setting/          # AppShortcuts / WebEngines 两个子面板
    ├── components/           # 结果列表、搜索框、快捷键录制框、快捷导航等
    ├── hooks/                # 搜索、选中、剪贴板等逻辑
    └── utils/accelerator.ts  # 组合键归一化与展示（⌥⌘W 之类）
```
